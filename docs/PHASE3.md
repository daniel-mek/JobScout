# Phase 3 implementation checkpoint

Implemented deterministic requirement/skill extraction with original evidence, required/preferred/uncertain distinctions, conservative aliases, description-led early-career classification, explicit hard-conflict checks, separate weighted Resume Match/Application Priority, capped priority on disqualification, recommendation classes and explanations. Projects are never treated as professional years. Scores are provisional assessments, not interview probabilities.

JobRequirement, JobSkill and versioned owner-scoped JobMatch records persist through migration `5a54a22dd98b`. POST `/jobs/{id}/match` calculates one job after profile confirmation with session/CSRF authorization. The job page displays scores, warnings, evidence gaps, breakdowns and version references. Input fingerprints include job/profile/resume/settings/algorithm and freshness date; changed inputs create a new record. Repeating identical inputs reuses the record. Source-retention tightening deletes derived extraction/match evidence too.

The first implementation deliberately leaves ambiguous professional duration, subject equivalence, unrecognized requirements and missing pay periods unknown. Neutral 50 components are disclosed. No AI interpretation or external submissions occur. Role relevance uses confirmed experience-title overlap; this remains a conservative lexical baseline.

Remaining before full Phase 3 acceptance: durable background recalculation for bulk job/profile/settings changes; broader requirement fixtures and structured experience/education/certification comparison; complete geographic/authorization/relocation handling; configurable persisted scoring policies; worker and browser/native PostgreSQL verification of this phase. Current calculation is on demand for a single job, never a foreground sweep over the catalog. Phase 4 discovery has not been started. Hosting remains paused.

Validation at this checkpoint: 70 API/unit/integration cases pass on SQLite; Ruff/mypy, frontend lint/typecheck and production build pass. Browser tests could not launch because the browser download returned a truncated archive; no browser success is claimed. CI includes the extended match-page flow and native PostgreSQL checks. Existing legacy tests pass (163 cases, two private-fixture skips). This checkpoint does not claim the complete Phase 3 specification is finished.
