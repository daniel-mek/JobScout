# me/ (private)

Copy this folder to `me/` and fill it in. `me/` is gitignored, so nothing here ever reaches GitHub.

| File | What it holds |
|---|---|
| `master_profile.md` | Every fact about you: education, experience, projects, skills. The only source the prep kit may use. Mark anything uncertain **[confirm]**. |
| `voice.md` | How you write: words you avoid, tone, approved themes, any project-order rules. |
| `answer_bank.md` | Answers you've approved before, reused as starting points. |
| `resumes/swe.json`, `pm.json`, `it.json` | One file per resume variant, built into PDFs by `scout/build_resume.py`. See `resumes/example.json`. |
| `ntfy-topic.txt`, `dashboard.env` | Your private ntfy topic and dashboard settings. |
